# CECI Mobile — Civil Evidence & Claims Intelligence Application

Cross-platform React Native / Expo mobile application for site engineers, quantity surveyors, and contract claims specialists.

## Key Features
- **5 Live Infrastructure Contractor Portfolios:** Instant access to delay timelines, variation deviations, and LD shielding metrics.
- **Site Photo Evidence Capture:** Multi-modal timestamped, GPS-located evidentiary logging.
- **Hindrance Register Sync:** Real-time delay recording for CPWD Clause 5 and FIDIC Clause 20.1 compliance.
- **Stand-Alone Deployment:** Configured for Android (`.apk` / `.aab`) and iOS (`.ipa`).

## Local Development & Browser Testing
```bash
# In 03_civil_evidence_claims_intelligence/mobile:
npx expo start --web
```
