# WRAI Mobile — Water Resilience AI Application

Cross-platform React Native / Expo mobile application for municipal stormwater engineers, smart city command center operators, and disaster management officials.

## Key Features
- **5 Smart City Urban Flood Twins:** Instant telemetry on flood depths, surcharged conduits, and vulnerable asset protection.
- **Sponge City SUDS Blueprints:** View cost-efficiency rankings of micro-wetlands, bioswales, and permeable corridors.
- **Emergency Action Plans (EAP):** Automated standard operating procedures for cloudburst events.
- **Stand-Alone Deployment:** Configured for Android (`.apk` / `.aab`) and iOS (`.ipa`).

## Local Development & Browser Testing

# In 04_water_resilience_ai/mobile:
npx expo start --web
